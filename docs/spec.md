# 核心防线 · 合成战场

Browser-playable first-person 3D game with mobile twin-stick controls. Working title selected by implementer. Procedural military training grounds, sandbags, AI allies/enemies, movement/jump/prone, no blood. Visual target is realistic military equipment; this deliverable uses procedural 3D models, not photoreal assets.

Start with one level-1 knife. Win stage 1 for handgun, stage 2 for mine, stage 3 for grenade; upgrade from stage 4. Four independent weapon inventories, maximum level 500. Two equal weapons merge, grant gold, change appearance/type. Guns continuously generate silver. Silver purchases are limited to the highest obtained level in that category; gold may buy a higher gun after obtaining a level-2 gun. Copper buys skins.

1000 procedural stages. Random or self-selected class, drawn only from current owned guns; knife-only fallback. Each side has sequential statue, hidden small core, laser core. Only all three friendly cores destroyed causes loss. Destroy all enemy cores to win. Player and bots respawn; no time or elimination defeat. Core upgrades persist.

Weekly claims using Asia/Shanghai date: Mon 5 copper, Tue 5 silver, Wed 70 gold, Thu/Fri none, Sat level-1 gun, Sun level-3 gun. One claim per date. Local progress saving; corrupted data safely resets. No server account/cross-device sync.

Tunable assumptions: first gun earns 25 silver per second; gold merge reward and shop prices scale by level. Initial silver 150; core upgrade uses gold. Costs and rates visible. Campaign clearance unlocks rewards; daily guns don't bypass stage-4 merge lock. Extra copies of a newly unlocked type may be purchased with silver. Procedural 500-level catalog uses families and variants, not 500 bespoke assets.
