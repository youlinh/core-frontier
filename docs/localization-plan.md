# 本地化与 GitHub 发布计划

目标：将原《核心防线 · 合成战场》部署为独立的本地与 GitHub Pages 版本，沿用原玩法和界面。

来源：Sites `appgprj_6aeeaac0073c819193bdcd1317eee8a8`，源码提交 `50981708a76b7a39485181d24ba074558b59d90e`。

实现选择：保留 `dist/` 中的静态页面及本地 Three.js 资源；增加零依赖 Node.js 启动器。GitHub 新建公开仓库 `youlinh/core-frontier`，Actions 验证后部署 `dist/` 到 Pages。原 Sites 版本不参与此次发布。

1. 迁移需要的源码、测试和文档，不导入原仓库的凭据、Sites 身份文件及已提交的 node_modules。保留来源快照在本机忽略目录 `.sites-checkout/`。
2. 增加 `npm start` 与 Windows 启动入口，验证页面、模块、MIME 类型、HEAD、404 和路径越界处理。
3. 补充中文使用说明及 Pages 工作流；运行完整测试、语法检查和桌面/手机浏览器检查。
4. 初始化 Git，核对待提交内容，推送 GitHub，启用 Pages 并跟进工作流到成功；验证线上页面与模块响应。

验收：本地可启动并进入战斗；全部自动测试通过；仓库可访问；Pages 部署成功且公开网址可打开。

完成记录：以上四步已完成，16 项测试通过，线上七份资源与发布提交一致；详细验证和发布证据见 `deployment.md`。

边界：继续使用程序生成的 1000 关和 500 级武器，保持原有简化三维表现。存档属于各浏览器与各网址，原 Sites、本地、Pages 的进度不会自动互通；本次不添加云端账号或跨设备存档。
